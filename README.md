# Digital Systems and Embedded Development Coursework

A working archive of VHDL and embedded-C projects completed across digital-systems and microcontroller coursework. The repository documents progression from combinational logic through finite-state machines, display systems, timers, and MSP432 firmware.

## Selected Work

- Signed calculator and seven-segment display modules
- Parameterized counters, timers, muxes, and delay units
- Vending-machine finite-state-machine designs and testbenches
- Shifting display and soda-machine logic
- MSP432 GPIO, timers, UART, OLED, and robotic-hand experiments

## Technologies

VHDL, C, Intel Quartus Prime, ModelSim, Code Composer Studio, MSP432, finite-state machines, digital logic, FPGA workflows, and embedded peripherals.

## Organization

- `DSD_LAB_CLASS/` — VHDL labs and simulations
- `CPET_DSD_Class_HW/` — digital-systems homework
- `Elie_Kalouche_CPET253/` — MSP432 and embedded-C coursework

> This is a coursework archive rather than a single polished application. Standalone portfolio projects are maintained in separate repositories.
